Info Penting Login Pertama

Karena aplikasi ini menggunakan Google Drive API pribadi untuk memutar musik langsung dari folder akunmu, Google akan memunculkan peringatan keamanan "Google hasn't verified this app" saat pertama kali login. Ini normal untuk aplikasi custom/pribadi.

1
Klik tombol "Advanced"

Ketika pop-up login Google muncul dan memberi peringatan, cari tombol/teks Advanced di bagian kiri bawah.

2
Klik "Go to ChloroWave" lalu "Allow"

Klik teks yang muncul di bawah, lalu klik Allow untuk izinkan akses Drive.

Go to ChloroWave (unsafe) ? Allow ? Selesai!
Login berikutnya langsung masuk — peringatan ini hanya muncul sekali.
